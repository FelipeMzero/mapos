Informação sobre a Arquitetura (Map-OS + Supabase + Pages)

1. Banco de Dados no Supabase (PostgreSQL): O script completo de criação com todas as 34 tabelas, relacionamentos, permissões e usuário administrador está disponível no arquivo supabase/schema_mapos_postgres.sql no repositório.
2. Hospedagem PHP vs. GitHub Pages: O GitHub Pages hospeda páginas web estáticas (HTML/JS/CSS). Para a versão completa clássica em PHP (CodeIgniter 3 com geração de PDF e relatórios), execute localmente via XAMPP ou hospede em plataformas como Render, Railway ou Docker VPS.

Conexão com Supabase

Insira a URL e a Anon Key do seu projeto no Supabase para sincronizar as tabelas diretamente pelo navegador.
